# Brand assets

The prototype does not establish a final standalone logo or App Store icon. Included wordmarks reproduce the product name in the existing serif family, in black and white. SVG text remains editable and depends on the installed font; outline it only after the final font is approved. Do not claim trademark clearance or a final approved logo.

`book-symbol.svg` is extracted from the existing UI icon system and is a reusable interface symbol, not an approved store icon. Create the final AppIcon asset set, export appropriate variants and validate in Xcode during the native build. Do not use the onboarding collage or a screenshot as an App Store icon. No third-party Altitude/Lassie/Origin branding is included.
