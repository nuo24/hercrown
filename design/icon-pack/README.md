# Interface icon pack

30 SVGs extracted from the final runtime. 24-unit coordinate system; round caps and joins; base stroke 1.65. Preserve the same outline language, with final component-specific weights from the reference. SVG `currentColor` is intentionally tintable for light/dark semantic ink. Photographic illustrations are not tintable.

`insights.svg` is the reader's lens with sparkle. It appears above the heart without a surrounding button well, border or shadow. Maintain a full native hit target even though the visible symbol is smaller.

`whatsapp.svg` is a custom WhatsApp-like contact glyph used in a mock contact badge. It is not official WhatsApp brand artwork. Confirm official brand assets/usage requirements before external production branding.

Lucide paths retain the included ISC license. Other simple custom paths were authored within the prototype. Use SF Symbols only when the resulting weight/shape meets the reference. Keep the custom insight lens where a generic substitute loses the design.
