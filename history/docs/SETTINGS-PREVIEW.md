# Detailed Settings mockup

Settings destinations are standalone in-app pages with back navigation. Reading topics no longer enter onboarding. Replay onboarding has been removed from Settings; the outer preview toolbar still provides an explicit restart control.

Your account includes a working local photo picker, preview, remove/reset action, name/email/bio fields and Save profile. Images accept JPG/PNG/WebP up to 10 MB and are center-cropped to a 320px JPEG for local storage. Nothing uploads to a server. Profile names also update the Home greeting. Fields are escaped before display.

Reading topics save without changing onboarding completion. Appearance has dedicated light/dark options. Subscription shows free-plan status, opens the optional paywall and includes a mock restore notice. Contact and support pages have topic selectors, message preview forms, WhatsApp mock details and support FAQs. About, privacy, terms and credits have full placeholder sections. No messages are transmitted and no purchases are processed.

Verified in browser: selected an existing project meadow image through the file picker, observed photo-ready status, saved profile and returned to Settings. Reading preference save returned to Settings without onboarding. Subscription and support destinations opened; support message preview confirmed nothing sent. Existing onboarding, streak and reader test suites and module syntax checks passed.

Surface refinement: removed the floating dock’s authored cyan/gold gradients in both themes. Neutral translucent glass retains blur and depth. Settings background is transparent over the live app gradient, extending through the full preview display, with status/home safe-area masks to keep scrolled text clear. Browser verified dock and scrolled Settings.
