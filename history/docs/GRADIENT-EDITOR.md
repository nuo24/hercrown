# Gradient editor

Open ios-preview.html. The editor sits outside the phone (below it on narrow windows). Changes apply live to all onboarding and app backgrounds, with white cards preserved for readability. Dark mode uses a muted version of the same colors.

Controls: first and second colors; optional third color; intensity; color reach; direction; Reset; Copy CSS. Preferences save locally under bible-gradient-v1, separate from onboarding progress. Reset restores the default sage/sky palette without resetting app data.

Verified: third color toggle, live intensity, persistence after reload, default reset, light/dark render, main Home surface. Implemented in the browser demo only.
