# 0005 · Offline translations: KJV, BSB, WEB

**Date:** 2026-11-02 · **Status:** accepted

**Decision:** Bundle public-domain translations for offline reading, like Scroll the Bible: King James Version, Berean Standard Bible and World English Bible, plus the Catholic Public Domain Version (offline in Scroll the Bible's current app). Each goes through the same verified build pipeline as KJV (pinned source checksum, full verse counts). Other translations (e.g. NIV) stay online via a licensed provider.
